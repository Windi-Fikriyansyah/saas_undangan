1. Ringkasan Proyek
SaaS Undangan Digital adalah platform berbasis web yang memungkinkan vendor undangan digital (Wedding Organizer, freelancer, dan agency) membuat, mengelola, dan mendistribusikan undangan pernikahan digital secara masif kepada klien mereka.
1.1 Target Pengguna
Vendor Utama: Wedding Organizer, freelancer undangan, agency digital
End User Klien: Pasangan pengantin yang memesan jasa undangan dari vendor
Tamu Undangan: Penerima undangan digital personal

2. Arsitektur Sistem
2.1 High-Level Architecture
Sistem dibagi menjadi 4 layer utama:
Vendor Dashboard (Next.js) — antarmuka untuk vendor mengelola order, template, dan tamu
Klien Form Page — halaman pengisian data oleh klien via smart link unik
Undangan Page (SSG/ISR) — halaman undangan yang dilihat tamu, dirender statis untuk performa
Admin Panel — manajemen platform: vendor, template, billing, analitik
2.2 Diagram Alur Sistem
Vendor Dashboard
  └── Buat Order → Pilih Template → Input Data Minimal
        └── Generate Smart Link (token 30 hari)
              └── Kirim ke Klien via WA

Klien Form Page (link unik)
  └── Step 1: Data Pasangan
  └── Step 2: Detail Acara (akad, resepsi, Maps)
  └── Step 3: Galeri Foto (upload)
  └── Step 4: Musik (library / upload)
  └── Step 5: Data Tamu (Excel upload / manual)
  └── Submit → Undangan LIVE otomatis

Undangan Page
  └── undangan.com/[slug]?to=[nama-tamu]
  └── Render nama tamu dinamis
  └── RSVP, Ucapan, Galeri, Maps, Musik
  └── Tracking: buka, device, waktu

5. Fitur & Modul
5.1 Vendor Dashboard
Registrasi & Login (email/password + Google OAuth)
Dashboard ringkasan: total order, undangan aktif, tamu RSVP, quota tersisa
Manajemen Order: buat baru, lihat status, edit minor, hapus
Generate & kirim Smart Link klien (tombol "Kirim via WA" langsung)
Manajemen Tamu: list tamu, filter status, blast WA, export Excel
Analitik: undangan paling banyak dibuka, jam ramai, conversion RSVP
Billing & Upgrade paket (integrasi Midtrans/Xendit)
5.2 Klien Form Page (Smart Link)
Multi-step form mobile-friendly (progress bar visual)
Step 1: Data pasangan (nama, foto profil)
Step 2: Detail akad & resepsi (tanggal, jam, lokasi, Google Maps link)
Step 3: Upload foto galeri (drag & drop, kompres otomatis)
Step 4: Pilih musik dari library atau upload sendiri
Step 5: Input tamu — upload Excel template atau manual satu-satu
Preview langsung sebelum submit
Auto-save per step (jangan sampai data hilang kalau tutup browser)
5.3 Halaman Undangan (Guest View)
Cover dengan foto & nama pasangan + countdown timer
Section detail acara (akad & resepsi) dengan tombol "Buka Maps"
Galeri foto dengan lightbox
Musik otomatis play (dengan kontrol mute)
Guestbook: kolom ucapan & doa dari tamu
Tombol RSVP (Hadir / Tidak Hadir / Ragu) dengan konfirmasi jumlah
Nama tamu personal tampil di bagian atas ("Kepada Yth. [Nama Tamu]")
Tombol share ke WA (tamu bisa forward undangan ke keluarga)
5.4 Admin Panel (SaaS Owner)
Manajemen semua vendor: daftar, status plan, usage, suspend/aktifkan
Manajemen template: upload, edit config, aktif/nonaktif
Monitoring: total undangan aktif, traffic, error rate
Revenue dashboard: MRR, churn, new subscriber
6. Sistem Template Engine
6.1 Konsep: JSON-driven rendering
Setiap template hanya menyimpan konfigurasi di database (JSON), bukan halaman HTML terpisah. Satu render engine membaca JSON config + data undangan, lalu menghasilkan tampilan final.

7. Sistem Personalized Link Tamu
7.1 Konsep URL
Master URL  : undangan.com/budi-ani
Tamu 1      : undangan.com/budi-ani?to=Pak+Rudi
Tamu 2      : undangan.com/budi-ani?to=Bu+Sinta
Tamu 3      : undangan.com/budi-ani?to=Keluarga+Besar+Hasan
7.2 Cara Kerja Teknis
Parameter ?to= dibaca oleh render engine di client-side (Next.js useSearchParams)
Nama tamu ditampilkan di bagian atas undangan secara dinamis
Setiap load page dengan ?to= → sistem catat event ke tabel guests (open tracking)
Tamu gak perlu login — identifikasi via kombinasi slug order + nama tamu di param
7.3 Input Data Tamu oleh Klien
Opsi A: Upload Excel/CSV
Klien download template Excel yang disediakan sistem, isi data tamu, lalu upload. Sistem parse otomatis dan generate entri per baris.
Opsi B: Input Manual
Form tambah tamu: Nama, Nomor WA, Jumlah Kursi, Kategori
Bisa tambah satu per satu atau bulk paste

8. Blast WA & Sistem Notifikasi
8.1 Alur Blast WA ke Tamu
Vendor klik "Kirim Undangan ke Semua Tamu" di dashboard
Sistem queue semua nomor tamu ke job processor (Bull/BullMQ dengan Redis)
Tiap job kirim WA via API (Fonnte/Wablas) dengan pesan personal
Delay antar pesan 1-3 detik untuk hindari rate limit WA
Status pengiriman update realtime di dashboard vendor

9. Multi-Tenancy & Keamanan
9.1 Isolasi Data per Vendor
Semua tabel utama memiliki kolom vendor_id — query selalu di-filter dengan vendor_id dari session aktif
Row-Level Security (RLS) di Supabase/PostgreSQL sebagai layer keamanan tambahan
Vendor tidak bisa mengakses data vendor lain meski tahu ID-nya
9.2 Custom Domain (Tier Business)
Vendor daftarkan custom domain mereka sendiri di dashboard
Sistem generate instruksi DNS (CNAME ke domain SaaS)
SSL certificate otomatis via Cloudflare/Let's Encrypt
Undangan klien mereka berjalan di domain sendiri, tanpa nama platform terlihat
9.3 Smart Link Keamanan
Client token untuk form pengisian: JWT atau random UUID 64 karakter, expired 30 hari
Token single-use: setelah data disubmit, token tidak bisa dipakai untuk edit ulang tanpa approval vendor
Rate limiting pada endpoint submit data klien dan RSVP tamu
9.4 Upload Keamanan
File upload divalidasi tipe (hanya JPG/PNG/MP3/XLSX) dan ukuran maksimum
Virus scan via ClamAV atau integrasi layanan pihak ketiga sebelum disimpan ke storage
File disimpan di path per-vendor di R2/S3, bukan path publik bersama

11. Roadmap Pengembangan
Phase 1 — MVP (Bulan 1–3)
Vendor auth + dashboard dasar
Smart link klien + form pengisian multi-step
Render engine template (5–10 template dasar)
Personalized link tamu + RSVP
Tracking buka undangan
Notifikasi WA manual (vendor kirim sendiri via link WA Web)
Payment Midtrans (subscription Starter & Pro)
Phase 2 — Growth (Bulan 4–6)
Blast WA otomatis (integrasi Fonnte/Wablas)
Reminder otomatis (klien & tamu)
Template premium (10–15 template)
Export Excel tamu
Analitik dashboard vendor
Admin panel SaaS owner
Phase 3 — Scale (Bulan 7–12)
White-label & custom domain (tier Business)
Multi-admin per vendor
Import Google Contacts
API publik untuk integrasi pihak ketiga
Custom template request (layanan premium)
Mobile app vendor (React Native)
